# Code of Conduct

Scantrix is committed to maintaining a professional, respectful, and focused environment for contributors and users.

---

## Expected Behavior

Participants are expected to:

- Communicate respectfully and constructively
- Focus on technical merit and project goals
- Be open to feedback and differing perspectives
- Act professionally in discussions and reviews

---

## Unacceptable Behavior

The following will not be tolerated:

- Harassment, discrimination, or offensive language
- Personal attacks or inflammatory comments
- Disruptive or unproductive behavior
- Misrepresentation of the project or its maintainers

---

## Enforcement

Maintainers are responsible for enforcing this code of conduct.

Actions may include:

- Requesting changes in behavior
- Removing comments or contributions
- Restricting or removing access to the project

---

## Scope

This code of conduct applies to:

- GitHub issues
- Pull requests
- Discussions related to the project

---

## Reporting

If you experience or observe unacceptable behavior, please report it to:

support@scantrix.app

All reports will be reviewed and handled appropriately.

---

## Final Note

This project prioritizes clarity, professionalism, and technical quality. Contributions and discussions should reflect those standards.
